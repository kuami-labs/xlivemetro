# Code de conduite

XLiveMetro veut être un projet accueillant pour toutes et tous, quels que soient l'âge, l'origine, le genre, l'identité, l'orientation, le handicap, l'expérience, la religion ou le niveau technique.

## Ce que nous attendons

- Être respectueux et bienveillant, en particulier envers les nouveaux contributeurs.
- Critiquer le code et les idées, jamais les personnes.
- Accepter les retours avec ouverture, et reconnaître ses erreurs.
- Privilégier ce qui est bon pour le projet et la communauté.

## Ce qui n'est pas acceptable

- Insultes, moqueries, attaques personnelles ou politiques.
- Harcèlement, public ou privé.
- Langage ou images à caractère sexuel.
- Publier des informations privées d'autrui sans son accord.
- Tout comportement qu'on jugerait raisonnablement inapproprié dans un cadre professionnel.

## Où il s'applique

Partout où le projet est représenté : dépôt, issues, pull requests, discussions, et échanges en son nom.

## Signaler un problème

Écrivez aux mainteneurs à **[adresse email du projet à définir]**. Chaque signalement est traité rapidement et en toute confidentialité.

## Conséquences

Selon la gravité, les mainteneurs peuvent : avertir, masquer ou supprimer un contenu, exclure temporairement ou définitivement une personne du projet.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/), version 2.1.
